# System requirements — Thermostat

## SYS-1 — Temperature regulation
The system shall keep room temperature within ±0.5 °C of the setpoint.
Verification: demonstration

## SYS-2 — Safety cut-off
The heater shall be switched off whenever the measured temperature exceeds 35 °C.
Verification: test

## SYS-3 — Setpoint range
The user shall be able to set a setpoint between 5 °C and 30 °C.
Verification: test
